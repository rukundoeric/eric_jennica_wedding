# Eric & Jennica – Wedding Website (replica)

Open `index.html` in a browser to preview: the envelope page opens `home.html` when the envelope is clicked.

## What's here
- `index.html` – "You are invited!" envelope page
- `home.html` – full invitation: Save the Date, details, venue (with map), entourage, gallery, attire guide, gifts, FAQ, RSVP
- `00_…` – `08_…` – images used by the pages (organised by section)
- `index.csv` / `manifest.csv` – list of every image and where it came from
- `_build/` – the captured source and the script used to generate `home.html` (not needed online)

## Fonts (Google Fonts, loaded online)
Old Standard TT (headings), Noto Serif (text), Licorice (script names), Great Vibes (attire script).

## Publish for free (Netlify)
1. Go to https://app.netlify.com/drop
2. Drag this whole `eric-jennica-site` folder onto the page.
3. You get a link like `https://something.netlify.app` – rename it in Site settings.

Note: the music button (YouTube) and the map only work when the site is opened from a web address, not from a file on your computer.
